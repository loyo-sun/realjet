## Visible production status

The management system brings selected process and equipment information into a coordinated production view. Its functions are defined around the actual workflow, user roles and data available from connected equipment.

## Project-defined functions

Possible functions include production scheduling, workstation status, equipment monitoring, alarms and reporting. Interfaces with third-party systems depend on agreed protocols, responsibilities and cybersecurity requirements.

## Integration inputs

An initial assessment requires the production process, equipment list, control architecture, required user roles and reporting expectations. The final data points and integration boundary are documented before implementation.
