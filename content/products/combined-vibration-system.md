## Consolidation matched to the mould

The vibration arrangement is selected according to component geometry, mould structure, concrete characteristics and placement sequence. Multiple vibration methods can be coordinated where the process requires different consolidation zones.

## Controlled operation

Mounting, vibration parameters, control groups and operator access are developed with the mould and workstation layout. The aim is a repeatable process that can be verified using agreed product-quality criteria.

## Required technical information

Provide mould drawings, component geometry, concrete mix range, placement method and target cycle. Trial and acceptance requirements should be defined for the actual mould and concrete used by the project.
